# Environment variables untuk Coolify — stack docker-compose.coolify.yml
# Referensi untuk Coolify → Environment Variables. Nilai di bawah placeholder:
# ganti dulu sebelum deploy.
#
# PENTING saat memakai Developer view: menyimpan isi editor akan menghapus entri
# yang tidak ada di dalamnya. Jangan menimpa seluruh daftar pada resource yang sudah
# berjalan — pertahankan entri `SERVICE_PASSWORD_64_BETTERAUTH` dan
# `SERVICE_HEX_32_IPHASHSALT` yang dibuat otomatis Coolify. Untuk resource yang sudah
# ada, paling aman ubah scope lewat Normal view.
#
# `# coolify: buildtime=false` di atas setiap variabel wajib dipertahankan: compose hanya
# membutuhkan env ini saat runtime. Tanpa itu Coolify menyuntikkan ratusan ARG ke semua
# stage Dockerfile dan deploy gagal "Argument list too long". Direktif harus langsung di
# atas variabelnya (jangan disisipi baris kosong/komentar lain).
